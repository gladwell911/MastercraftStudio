- (direction) Headless express：依据本会话已确认需求与当前代码，输出实现前规格，不修改程序。
- (decision) 入口固定为顶部应用(&A)菜单的查看聊天信息，仅 Codex/Kimi 会话可用。
- (capability) CAP-1 用户可从应用菜单打开当前 Codex/Kimi 聊天的独立信息列表，列表焦点可用键盘浏览，Esc 关闭并恢复先前焦点。
- (capability) CAP-2 信息列表展示当前上下文已用百分比、精确已用 token、精确窗口总 token，并随权威数据变化更新。
- (capability) CAP-3 信息列表展示当前原生会话自创建以来累计 token，并与当前上下文占用分开。
- (capability) CAP-4 Codex 展示周额度剩余百分比和当地具体重置时间，仅在服务端提供周窗口时展示。
- (capability) CAP-5 Kimi 展示五小时已用百分比和当地具体重置时间，以及七日已用百分比和距重置时长。
- (capability) CAP-6 信息列表可见时随用量事件、低频账号刷新及本地倒计时更新，后台刷新不抢焦点、不重置选择。
- (capability) CAP-7 登录方式、窗口或字段不支持/不可得/请求失败时逐项明确提示，不显示伪造零值或过期值为实时值。
- (constraint) Codex 当前上下文采用最近用量 last.totalTokens 与动态 modelContextWindow；累计采用 total.totalTokens，不把累计当上下文。
- (constraint) Kimi 当前上下文采用 status 的 context_tokens/max_context_tokens；累计读取 snapshot 的真实 usage，不能使用普通 session 的零值占位；缓存 token 不能重复计算。
- (constraint) Codex 周窗需由 windowDurationMins 验证，剩余额度为 100-usedPercent；Kimi OAuth quota 的 limit5h/limit7d 仅提供 usedRatio 与可选 resetAt，无绝对总额度。
- (constraint) 仅查询当前聊天匹配的原生 thread/session；异步回调必须校验聊天、会话、账号及窗口生命周期。
- (constraint) 遵守 AGENTS.md：屏幕阅读器键盘焦点稳定，后台无可见变化不调度 UI 工作、不重绘列表、不改选择或写状态；GUI 测试串行。
- (decision) 信息面板作为独立列表，不复用回答列表；Esc 先关闭面板，不能落入主窗口的最小化到托盘行为。
- (assumption) Kimi 会话累计 token 定义为 snapshot 中 input_tokens+output_tokens；cache_read_tokens 是 input 子集，不重复相加。
- (question) 当额度存在多 bucket 或订阅附加额度时，是否仅显示 codex 主周窗并省略其他 bucket；本规格暂按主 codex 周窗。
