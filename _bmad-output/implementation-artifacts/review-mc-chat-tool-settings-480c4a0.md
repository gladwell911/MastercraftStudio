四个视角均已按项目规定串行完成。五组是本轮修补输入，其中前两组影响请求或模型归属。未发现需要用户选择的修复取舍。

- 核对了 Kimi 手动审批与计划模式切换后的请求断言，以及 AGY 账户不适用响应的断言，两处当前测试均有空白。现有证据没有显示两项实现出错；如修改相应请求或状态路径，定向补验即可。
- AGY 不提供额度账号 ID 或有效重置时刻的情形已在工单 07 记录。交接输入过长由原生拒绝，目前没有可用于相同口径预判的本地阈值。目标会话尚未确定时暂缓 AGY 原生同步会推迟一次刷新，现有证据未显示问答丢失。
- 原有 AGY 历史的系统提示行会影响部分原生回放索引，固定基线已经按物理行逐项匹配；本轮新功能引入的用量错误列入第 5 项。已有读屏和冻结包的现场证据边界沿用工单 02，不据源码测试推断用户实际听感或卡死已消失。
