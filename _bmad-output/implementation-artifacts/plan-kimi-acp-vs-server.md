## 最小对照

在笔记本上用同一份已核对版本和 SHA-256 的 `kimi.exe` 2.6.3 比较 `kimi acp` 和官方 Server API。各路线分别使用结构相同的临时 `KIMI_CODE_HOME`、工作区副本和 MC 测试历史。固定模型、权限策略、提示词、输入顺序、文件内容和故障注入时机。记录路线与环境，不读取日常会话和真实凭据，不启动或替换日常 MC。

1. **隔离阶段**。从真实 CLI 进程完成初始化、建立会话、首问和一次受控工具任务。使用本地可控响应验证消息和权限的确定性边界，再按下表扩展。固定模板分别在两条路线执行，捕获脱敏事件时间线及最终持久化记录。
2. **真实阶段**。由两条路线分别使用同一测试账号或权限与额度等价的独立认证、相同模型，在两份临时工作区重跑关键路径。工具任务仅操作临时夹具。首条可见文本、执行进度、审批和最终回答须从隔离 MC 界面观察。仅客户端协议探针通过时，记为底层能力已观察。每条路线至少三次正常首问与三次故障恢复，保留单次数据和中位数。

## 任务与判据

| 功能 | 两条路线执行同一任务并记录 |
| --- | --- |
| 聊天与流式 | 同一会话连续两问，包含中文和非 BMP 字符。对比流式片段拼接、最终正文、第二轮上下文以及 UI 与持久化文本。计首条可见正文到达时间、终态时间。 |
| 工具与审批 | 在临时目录读取测试文件，再分别批准和拒绝写入同一目标的两次独立任务。核对审批归属、读屏可读性及实际文件状态。拒绝后无写入，未经批准不提前执行。 |
| 执行过程 | 在隔离任务中产生读文件、写文件和运行轻量命令等可控步骤，核对顺序、状态、归属、错误反馈和重开后的历史。记录无法映射到 MC 的步骤或字段。 |
| 取消 | 触发可观察的长任务后取消，核对对应任务进入权威终态、取消耗时及后续无残余写入。取消后的新任务能正常提交。 |
| 重连与恢复 | 分别测试任务完成后断开、任务执行时中断通信、CLI 冷重启。验证会话加载或续开、未决任务处理、完整文本与步骤、去重和终态。区分只读历史恢复与进行中任务重新接上，禁止自动重发状态未决的任务。 |
| 途中追问 | 长任务可见后提交一条改变当前任务目标的指令，核对有无真正同轮更新，以及原任务、追问、终态和输出归属。只能排队或取消后另起时，记为降级并展示行为。 |
| 用量 | 核对单轮 token、上下文、会话累计与缓存命中率是否有可追踪的有效数据来源。对比分母、回合归属、冷重启复现和缺失字段显示。 |
| 附件 | 使用独立的合成 TXT、PNG 与 MC 已支持的其他文件类型验证能正确读出标记；覆盖含中文和空格的路径、附件随会话恢复，以及不可用类型的可读提示。协议宣告的媒体类型只作线索。 |

## 记录与决策门槛

逐次记录机器与架构、CLI 版本和哈希、协议及协商能力、启动路径、任务编号、脱敏事件、首条文本和终态耗时、取消与恢复耗时、状态/正文/文件核对结果。统计重复派发、串会话、审批错配、终态丢失和非授权写入次数。隔离协议探针、真实 CLI 与冻结 MC 的结果各自注明来源。

每项结果标为**通过**、**可用但降级**、**失败**或**未验证**。通过要求输入、过程、权威终态与落盘满足判据。降级须记载确切替代行为和用户损失。协议宣告、偶尔可用或只有模拟证据均不能替代对应真实验收。

两条路线都必须通过流式聊天、工具允许/拒绝、取消、任务归属和断线后安全结算，且无非授权写入、串会话或未决任务重复派发。任何路线涉及执行过程、途中追问、用量、旧历史或附件降级，先据实列明用户可见差异，由用户决定能否接受。满足门槛后比较维护成本、可接受的功能差异、测试耗时和升级兼容性。若均未满足，保留当前生产路径，依据最小失败证据继续验证。
