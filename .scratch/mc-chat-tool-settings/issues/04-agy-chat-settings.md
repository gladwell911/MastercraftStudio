# 04 AGY 直接新建并应用每次提问的设置

**交付行为**　通过相同控件直接新建 AGY，默认工作目录沿用 Codex，用户在已有 AGY 聊天中可调整下一次独立提问。

**前置工单**　01 Codex 的四个组合框与新回合设置

**状态**　resolved

**验证记录**　AGY 1.5.18 在真实 wx 主事件循环下完成八轮，核对三个设置变更组合、同一原生会话、两条排队快照和自动审批。重开后已持久化认领但无可靠终态的旧问题保留待确认，避免重复发送。

## 验收

- [ ] 新建无目录选择和二次配置弹窗，未显式指定新工作位置时使用默认目录。AGY 真实选项中文化，默认 Gemini 4 Neon、高、自动。无独立快速服务时速度显示“标准”。
- [ ] 菜单工具模式与启动时跳过工具审批各自生效。核实真实启动、工作目录、无逐次审批的实际工具操作与支持的选项。缺失默认值时给出可读提示。
- [ ] 上轮执行中改变模型或强度并发送，两条独立提问各持自己的设置快照，按顺序开新回合。未改配置保持已有发送方式，原回合内追加沿用原设置；切换失败保留可恢复的问题。
- [ ] 在隔离配置下从 MC 的正常入口用真实后端先完成至少两条问答，分别验证只换模型、只换强度、两者同换。用原生回读、服务回执或请求参数核对有效配置、相同会话 ID，以及后续回合仍能利用两条旧问答的内容。
- [ ] 未改配置时本地原回合的正常纯文字追加保持可用；持久化结果和队列之间无重复终答。
