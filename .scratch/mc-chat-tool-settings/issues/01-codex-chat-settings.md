## 验收

- [ ] 键盘依次访问工具、模型、推理强度、速度并听到中文名称与选择。工具顺序为 Codex、AGY、Kimi Code、其他。Codex 在工具框只出现一次，其具体模型按真实目录列出。
- [ ] 真实可用模型、推理档位和服务档位联动。模式在工具菜单；新聊天采用默认协作模式、never 和完整访问，原有 Codex 标准/快速仍可用。核对独立测试目录中的实际工具操作。
- [ ] 上轮执行中改变模型或强度并发送，两条独立提问各持自己的设置快照，按顺序开新回合。未改配置保持已有发送方式，原回合内追加沿用原设置；切换失败保留可恢复的问题。
- [ ] 在隔离配置下从 MC 的正常入口用真实后端先完成至少两条问答，分别验证只换模型、只换强度、两者同换。用原生回读、服务回执或请求参数核对有效配置、相同会话 ID，以及后续回合仍能利用两条旧问答的内容。
- [ ] 保留其他工具的既有入口。用 wx 自动化核对切换、焦点与错误留稿。
