## 验收

- [ ] 无独立快速档位时速度显示“标准”，Highspeed 作为供应商模型列出，保留已公布的额外用量提示。只呈现实机支持的推理选项。
- [ ] 新建默认关闭计划模式并选择 auto，分别验证创建、配置回读、原账户与运行环境下的实际工具审批行为。
- [ ] 上轮执行中改变模型或强度并发送，两条独立提问各持自己的设置快照，按顺序开新回合。未改配置保持已有发送方式，原回合内追加沿用原设置；切换失败保留可恢复的问题。
- [ ] 在隔离配置下从 MC 的正常入口用真实后端先完成至少两条问答，分别验证只换模型、只换强度、两者同换。用原生回读、服务回执或请求参数核对有效配置、相同会话 ID，以及后续回合仍能利用两条旧问答的内容。
- [ ] 分别核对受支持的 2.5.3 与 2.6.3。未改设置时前者按原协议判断同轮追加或排队，后者维持独立排队；若协议不能完成某个场景，明确记录实际限制。
