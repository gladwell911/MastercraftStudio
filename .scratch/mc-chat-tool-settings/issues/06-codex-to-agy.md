# 06 发送时从 Codex 接续到新的 AGY 会话

**交付行为**　Codex 聊过几轮后改选 AGY，用户实际发送时才在原目录创建 AGY 聊天，第一次请求带完整可见问答。

**前置工单**　04 AGY 直接新建并应用每次提问的设置

**状态**　ready-for-agent

[完整规格](../../../_bmad-output/specs/spec-mc-chat-tool-settings/SPEC.md)

## 验收

- [ ] 仅选择或切换回 Codex 不创建会话，不消耗回合。发送时按源聊天的真实目录、截止点取全部已完成且可见的问答，按原顺序、发言人和换行保留原文，另列本次问题。
- [ ] 源历史不含未结束片段、内部执行轨迹或历史附件二进制。仅发送本次明确附带的文件。超限、目录无效或明确拒绝时不截断、不摘要、不发布空聊天或半发历史，原聊天与草稿、附件可继续使用。
- [ ] 真实 Codex 已完成至少两轮后转真实 AGY，核对两个不同原生会话、同目录、仅一次初始提问、原文内容和原 Codex 仍可继续；第二问不重复交接。首次提交响应未知时按原请求/会话对账，避免重发。
