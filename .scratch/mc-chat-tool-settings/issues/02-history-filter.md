# 02 隐藏终端聊天并改善历史浏览响应

**交付行为**　勾选 Alt 工具菜单的“隐藏终端聊天”，只浏览 MC 创建的会话，同时降低历史列表刷新对键盘和读屏的影响。

**前置工单**　无，可以立即开始

**状态**　ready-for-agent

[完整规格](../../../_bmad-output/specs/spec-mc-chat-tool-settings/SPEC.md)

## 验收

- [ ] 两处菜单共享勾选值，重开保留。MC 创建后曾由终端续聊的记录保留；原生终端导入的旧记录在整表、增量、置顶和快捷键导航一致隐藏。取消勾选能恢复，历史数据与进行中的任务完整。
- [ ] 在隔离环境重现接近 1,224 条历史的负荷，分别测全量与过滤、同步中与空闲时按键到焦点/选中变化及主线程长操作。对比优化前后并区分实测 UI、读屏和单项函数耗时。
- [ ] 按实测结果消除重复数据库查询或列表扫描。未变化时不重复重绘或抢焦点；未复现的冻结注明证据缺口。
